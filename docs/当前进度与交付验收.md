## 已确认的用户配合

用户尚未开通店铺，可先完成淘宝个人店开通并能进入千牛卖家后台；不提供密码。为完成下一批真实搜索和 AI 验证，需要用户在本地配置 Tavily 与 OpenAI API Key；密钥不进入聊天或仓库。PostgreSQL 验收前需要启动本机 Docker Desktop。

开店后先核验该账号是否能使用 1688 代发及选定工具。账号登录、实名与授权在用户设备的官方页面完成。开发端负责整理明确操作步骤，不把寻找技术接入方案的工作交给用户。

## 下一批必须交付的结果

1. 启动验收（已完成本地基线）：按 README 步骤启动 PostgreSQL 和应用，页面可访问，数据重启后保留。仍需在用户日常启动环境复核一次操作体验。
2. 真实找货：应用自己发出查询，保存真实候选、链接和时间；不能用聊天里的搜索或预填示例代替。
3. AI 验证：接入可用模型，从真实商品资料提取规格，关键属性有证据，缺失值不编造。需要用户开通/充值服务时给出选定方案和本地配置步骤，不事后才告知依赖。
4. 接入验证：店铺就绪后核验真实代发入口、SKU 关联、待付款采购单和物流通道。不能只展示 mock。
5. 单品闭环：已验样商品从上架到正常订单、人工监督付款、发货、物流及对账可追溯。测试不制造虚假成交或评价。
6. 稳定性：重复事件不重复采购，外部结果未知时先核实，断网/登录过期可提示并恢复；明确日常运行时电脑是否须常开。

开店等待期间可继续 1–3；实际平台能力未验证前，不展开大量平台页面和生产适配。若账号或工具不支持某条链路，及时调整方案并明确剩余人工步骤。

## 最终交付定义

交付的是用户能启动、能连接实际服务、能完成限定业务流程、失败时能接管的系统。完成文档、漂亮页面或离线测试均不足以标记任务完成。硬性外部限制需在投入大量开发前揭示，不承诺未经验证的全自动能力。
